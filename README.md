# نادي منبر الشاب المبدع

مشروع واجهة React + Vite متصل بـ Supabase. هذه نسخة تطوير؛ لا ترفعها إلى الموقع المنشور قبل اجتياز الاختبارات.

## المتطلبات
- Node.js إصدار حديث يدعم Vite 8.
- المفتاح العام Publishable الخاص بمشروع Supabase فقط.

## التشغيل على الحاسوب
1. فك ضغط الملف.
2. افتح مجلد المشروع في Terminal أو PowerShell.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env.local`.
5. افتح `.env.local` وضع المفتاح العام في `VITE_SUPABASE_PUBLISHABLE_KEY`.
6. نفّذ `npm run dev` وافتح الرابط الذي يظهر.

## الأمان
- لا تضع `service_role` أو `sb_secret` في ملفات الواجهة أو Google AI Studio أو Cloud Run frontend.
- لا تغيّر أدوار الحسابات من المتصفح. مصدر الدور هو `profiles.role` وسياسات قاعدة البيانات.
- مراجعة طلبات العضوية والأنشطة تتم عبر دوال RPC الإدارية المحمية.

## حدود النسخة الحالية
- التحقق من العضوية يعتمد حالياً على معرّف مستخدم Supabase الكامل، لأن المخطط الحالي لا يحتوي على رقم عضوية مستقل.
- صورة QR المعروضة حالياً زخرفية وليست رمزاً قابلاً للمسح.
- لم يكتمل بعد اختبار البناء والاختبار الوظيفي على Supabase؛ لا تعتبر النسخة جاهزة للإنتاج قبل ذلك.


## تحديث إداري إضافي
- تتضمن بوابة المدير واجهة لتغيير دور الحساب إلى مشرف نشاط أو إعادته إلى عضو عبر الدالة المحمية `admin_set_profile_access`.
- تتضمن واجهة لإسناد الأنشطة إلى المشرفين وإلغاء الإسناد، بالاعتماد على سياسات RLS الموجودة في جدول `organizers`.
- عند إعادة المشرف إلى عضو، تحاول الواجهة إزالة تكليفاته السابقة.
- لا تضع مفاتيح Supabase السرية في الواجهة أو ملفات `.env` التي تُنشر. استخدم المفتاح العام Publishable فقط.

## حالة التحقق
لم يكتمل اختبار البناء في بيئة التحرير لأن تثبيت الاعتماديات عبر npm انتهى بمهلة زمنية ولم يتوفر مجلد `node_modules`. لذلك يجب تشغيل `npm install` ثم `npm run lint` و`npm run build` محلياً قبل النشر. هذه النسخة ليست تصريحاً بالنشر المباشر.

## ملاحظات تشغيل مهمة

- اسم النادي المعتمد في الواجهات هو «نادي منبر الشاب المبدع».
- رمز QR في بطاقة العضوية يُنشأ الآن كرمز QR فعلي يحتوي معرّف حساب Supabase (UUID)، وليس رسماً زخرفياً. المعرّف ليس كلمة مرور ولا يثبت وحده اعتماد العضوية؛ التحقق الحقيقي يتم بالرجوع إلى جدول `profiles` وحالة العضوية.
- تمت إضافة الاعتمادية `qrcode.react`؛ نفّذ `npm install` قبل `npm run build`.
- لا تضع مفتاح `service_role` أو أي مفتاح سري في ملفات الواجهة أو متغيرات `VITE_`. استخدم المفتاح العام Publishable فقط.
- لم يتم تغيير مخطط قاعدة البيانات أو بيانات الأعضاء في هذه النسخة.
